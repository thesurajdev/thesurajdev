# Publish the clear futuristic profile

Upload `README.md` and the complete `assets/` folder to the root of `thesurajdev/thesurajdev` on the `main` branch. Keep the `assets` paths intact.

## Design choices
- The animated hero keeps its typography static and high-contrast; motion is confined to the right-side HUD artwork.
- Body copy uses straightforward headings, plain language, descriptive project labels, and concise paragraphs.
- The signal divider is subtle so it separates sections without competing with them.
- GitHub stats use third-party services and may occasionally be unavailable; the main content remains readable without them.

GitHub README content does not execute arbitrary JavaScript or custom CSS. Animated GIFs and supported images are used for motion.
