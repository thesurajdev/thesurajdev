# Suraj Dev — Digital World

A futuristic, interactive personal portfolio designed as a small digital operating environment.

## Features
- Animated constellation canvas with connected particles
- Clickable work-category nodes that filter projects
- Filterable project cards linking to real projects/repositories
- Interactive command terminal (`help`, `about`, `projects`, `skills`, `contact`, `clear`)
- Responsive layout for desktop, tablet, and mobile
- Keyboard focus styles and reduced-motion support
- No build step, framework, API key, or backend required

## Publish with GitHub Pages
1. Create a public repository named `suraj-dev` under `thesurajdev`, or choose another project-repository name.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub Pages finishes deploying, open the published URL shown in the Pages settings.

For the expected repository name `suraj-dev`, the standard project-site URL is:
`https://thesurajdev.github.io/suraj-dev/`

## Important
GitHub Pages is static hosting. This project uses client-side JavaScript in the standalone site, which GitHub Pages serves normally. This is different from a GitHub README, where arbitrary JavaScript and CSS are not executed.

The page loads Manrope and DM Mono from Google Fonts. If fonts are unavailable, system fallback fonts are used. The particle background and terminal run locally in the browser; no user data is sent to a server.
