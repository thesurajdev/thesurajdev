## `01 / ABOUT`

I'm **Suraj Dev** — a digital marketer and creative technologist.

I bring together audience-first marketing, web development, and automation to make digital experiences more useful, discoverable, and measurable. I like solving practical problems, connecting systems, and turning ideas into tools people can actually use.

- **Growth:** SEO, content strategy, performance marketing, analytics
- **Engineering:** WordPress, Next.js, frontend experiences, API integrations
- **Automation:** n8n, webhooks, Google Sheets, connected workflows
- **Exploration:** AI-assisted tools, prototypes, and digital products
