CodeCanvas 1.7.11 · Free WordPress theme · GPL-2.0-or-later

Write real code inside WordPress.

CodeCanvas 1.7.11 is a standalone, code-first theme with a real-file Code Studio workspace and a scoped MCP server for AI clients. No page-builder onboarding, no required companion plugin — just your source files, an editor that writes to disk, and a recovery guard that undoes a bad write.

Requires WordPress 6.6+ and PHP 7.4+. Install with Appearance → Themes → Add New → Upload Theme.

codecanvas-site / front-page.php
<?php
// Your website lives in the child theme.
if ( ! defined( 'ABSPATH' ) ) { exit; }

get_header();

while ( have_posts() ) : the_post(); ?>
  <article class="cc-section">
    <h1><?php the_title(); ?></h1>
    <div><?php the_content(); ?></div>
  </article>
<?php endwhile;

get_footer();

Code Studio: a real-file workspace, not a page builder.

Browse and edit the actual PHP, CSS and JavaScript on the server. Files are read from disk and written back, with validation before every write.

▤

Edit real source files

Browse eligible files under wp-content/themes and wp-content/plugins. Create, rename and delete supported source files from the Explorer.

⌕

Search and jump

Full-text search across supported files, with results that open the editor at the matching line.

◧

Child-theme first

The framework parent is read-only in Studio. Website work happens in the CodeCanvas Site child theme, created only when you click the button.

⌫

Syntax checks before saving

PHP syntax errors are rejected before they touch disk. A save is refused if the file changed on disk since you opened it.

◔

Snapshot history

Three revisions per file are kept before every change. Compare a hash, restore a snapshot, and keep working.

▣

Focus mode & mobile

Hide the WordPress chrome to fill the screen (Ctrl/Cmd+Shift+M, leave with Esc). On phones the Explorer becomes a slide-in drawer with touch-sized controls.

Optional · off by default

Connect Claude, Cursor or any MCP client — with a scope you choose.

CodeCanvas ships a scoped HTTP MCP endpoint. Generate a token, pick the exact projects and tools an AI client can reach, and leave writes off until you need them. OAuth 2.1 with PKCE is supported for browser clients such as claude.ai.

  • Bearer token, stored only as an HMAC hash and shown once.
  • File writes and content writes are separate switches, both off by default.
  • Framework theme is never exposed; paths are validated and every write is snapshotted.
  • Calls are rate-limited and audited.
  • create_plugin scaffolds a plugin but never adds it to the write scope, and activation stays manual.

Recovery guard

A bad write is a one-request outage, not a file-manager repair.

Install the must-use guard and CodeCanvas restores the last snapshot automatically when a PHP fatal error comes from a theme or plugin file. Install, repair or remove it from MCP & Settings — nothing runs until you ask it to.

Built for the way you already work

Everything stays a normal WordPress record.

Content written over MCP is a regular page or post, so it stays editable in the block editor. Menus, settings and media go through normal WordPress APIs. CodeCanvas adds one menu with three destinations — Welcome, Code Studio and MCP & Settings — and does not replace the dashboard, block editor, media library, users, plugins or settings screens.

  • No Studio, MCP settings or CodeMirror assets load on public pages.
  • Homepage loads just 4 stylesheets and 2 scripts.
  • Translation-ready, threaded comments, custom logo and menus, wide blocks.

From install to a live build in three steps.

Recommended on local or staging first. Review the security model before enabling source writes or MCP on production.

◈

Install & activate

Upload codecanvas-1.7.11.zip and activate CodeCanvas. The Welcome screen shows the version, active theme, MCP state and recovery-guard status.

◈

Create the child theme

One explicit click in Code Studio creates and activates the CodeCanvas Site child theme and opens wp-content/themes/codecanvas-site. Existing files are never overwritten.

◈

Build — optionally with AI

Edit templates, CSS and JS in Studio, or enable MCP and connect Claude Code, Cursor, VS Code or claude.ai with the scope you choose.

Documented end to end.

A full product specification, security model and QA record ship with the theme. The automated suite passes 282 tests covering path policy, framework protection, MCP authentication and tools, sanitization, rate limiting and audit redaction.
